# AdSense ポリシー違反 調査レポート

## 却下理由
**有用性の低いコンテンツ（Low Value Content）**

Googleの判定：
「お客様のサイトは、弊社の定めるサイト運営者ネットワークのご利用要件を満たしていないと判断されました。」

---

## 問題の原因

### 結論
**アプリ画面（/app/）のコンテンツがGoogleクローラーに認識されにくい**

メトロノーム・タイマー・音源再生機能がある画面は、JavaScriptで動的に生成されるため、Googleクローラーから見るとコンテンツが少ない（または空の）ページに見える可能性がある。

### 技術的詳細

**`/app/index.html` の内容（クローラーが見る静的HTML）:**
```html
<body>
  <noscript>You need to enable JavaScript to run this app.</noscript>
  <div id="root"></div>
</body>
```

→ 実質22行、テキストコンテンツなし
→ 実際のアプリUIはJavaScript（2.3MB）で動的に読み込まれる
→ Googleクローラーがクライアントサイドレンダリングを完全に処理できない場合、「空のページ」と認識される

---

## 対策

### 実施内容
アプリ画面（メトロノーム・タイマー・音源再生）の下部に、各機能の使い方説明を追加する。

### 仕様
1. **配置場所**: 各機能の下部
2. **使用画像**: `assets/1.png`〜`assets/7.png`
3. **使用色**: `src/constants/theme.ts` で定義済みの色のみ
4. **表示切り替え**:
   - 審査中: 常時表示
   - 審査通過後: 「使い方はこちら」ボタンで表示/非表示を切り替え
