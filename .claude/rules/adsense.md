# AdSense 対策ルール

## 背景
AdSense審査で「有用性の低いコンテンツ」として却下されたため、アプリ画面に使い方説明を追加する。

## 説明文要素の作成ルール

### 1. 画像の使用
説明文に画像を使用する場合は、以下のファイルのみを使用すること：
- `assets/1.png`
- `assets/2.png`
- `assets/3.png`
- `assets/4.png`
- `assets/5.png`
- `assets/6.png`
- `assets/7.png`

### 2. 色の使用
アプリ内で定義済みの色（`src/constants/theme.ts`）のみを使用すること。

**使用可能な色:**

| 用途 | 色 |
|------|-----|
| Primary（青） | #3b7bff, #2d62cc, #1a3d80 など |
| Accent（オレンジ） | #ff9800, #ff6b35 |
| Background | #f5f5f5, #ffffff, #ebebeb |
| Text | #1a1a1a, #666666, #999999 |
| Border | #333333, #999999, #e0e0e0 |
| Success | #22c55e |
| Warning | #f59e0b |
| Error | #ef4444 |

**新しい色の追加は禁止**

### 3. 表示/非表示の仕組み
- 審査通過後は「使い方はこちら」ボタンで表示を切り替える形式に変更予定
- 現時点では説明文を常時表示（審査対策）
- ボタンを配置する前提でコンポーネントを設計すること

### 4. 配置場所
- メトロノーム・タイマー・音源再生機能の下部に配置
- 各機能の使い方を説明するセクションを追加

### 5. コンテンツ要件
- Googleクローラーが認識できるよう、静的なテキストコンテンツを含める
- 画像だけでなく、テキストによる説明も必ず含める
